# АРМ-112 — учебный симулятор подготовки диспетчеров экстренных служб

Тренажёр для обучения операторов дежурно-диспетчерских служб (ДДС) города Москвы работе с системой-112. Эмулирует рабочий процесс оператора (АРМ-112) в изолированном контуре: обучающийся принимает учебный звонок, заполняет карточку происшествия, а система автоматически сравнивает действия с эталоном сценария и оценивает по полям, порядку действий, времени и оформлению.

Решение подано на конкурс **«Лидеры цифровой трансформации 2026»**.

Полное ТЗ: `https://t.me/c/4363884787/3`.

## Технологии

- **Backend:** Python 3.14, Flask, Flask-SQLAlchemy, Flask-Migrate (Alembic), gunicorn, PyJWT, psycopg2, httpx, openpyxl, reportlab, pymorphy3, defusedxml; FastAPI/uvicorn/websockets (VoIP); llama.cpp + YandexGPT-5-Lite-8B (ИИ); Piper TTS + faster-whisper (голосовой диалог)
- **Frontend:** React 19, TypeScript, Vite, без сторонних UI-библиотек
- **БД:** PostgreSQL 16 (12+)
- **Форматы обмена:** JSON (основной), XML (настройки/АРМ), CSV/XLSX/PDF (отчёты)
- **Связь:** VoIP/SIP через локальный сервер (Asterisk, PJSIP, WebRTC)
- **Безопасность:** TLS/SSL внутри контура, RBAC, аудит действий с хэш-цепочкой, обезличивание по 152-ФЗ
- **Инфраструктура:** Docker/Docker Compose
- **ОС:** Windows 10/11, Linux Ubuntu 20.04+
- **Браузеры:** Chrome, Firefox, **Яндекс.Браузер** (актуальные версии)
