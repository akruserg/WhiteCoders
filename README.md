# Учебное ПО для подготовки оператора ДДС города Москвы с использованием ИИ

Тренажёр для обучения операторов дежурно-диспетчерских служб (ДДС) работе с системой-112 города Москвы. Эмулирует рабочий процесс оператора (АРМ-112) в изолированном контуре, с генерацией и оценкой сценариев на основе ИИ.

Полное ТЗ: `/docs/tz.pdf` (загрузить в репозиторий).

## План на неделю (кратко)

- **День 1** — фиксация API-контракта (`api.txt`), wireframes ролей, схема БД
- **День 2–3** — финальные макеты в Figma, бэкенд (auth, CRUD, моки вместо ИИ), вёрстка каркаса на моках

- **День 6** — отчётность, сквозное тестирование, черновик презентации и документации
- **День 7** — финальная сборка, багфиксы, подготовка 4 ссылок для сдачи, репетиция питч-сессии

## Технологии

- **БД:** PostgreSQL 12+
- **Форматы обмена:** JSON (основной), XML (legacy/конфиги), CSV (экспорт отчётов)
- **Связь:** VoIP/SIP через локальный сервер
- **Безопасность:** TLS/SSL внутри контура, RBAC, аудит действий
- **ОС:** Windows 10/11, Linux Ubuntu 20.04+
- **Браузеры:** Chrome, Firefox, Яндекс.Браузер (актуальные версии)
