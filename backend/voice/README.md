# arm_voice

Голосовой модуль тренажёра АРМ-112: озвучивает реплики «заявителя» (TTS) и
распознает речь оператора (STT). Работает полностью офлайн — обе модели
читаются с локального диска, в интернет сервис не обращается.

Вынесен в отдельный образ (`python:3.12`), а не встроен в `arm_voip`
(`python:3.14`): на момент разработки часть колес ML-экосистемы
(`onnxruntime`, `ctranslate2`) собрана и проверена прежде всего под 3.12.
Тот же прием уже применен в проекте для `llm/` (отдельный рантайм llama.cpp).

## Модели

- **TTS**: [Piper](https://github.com/rhasspy/piper) — офлайн-синтез, ONNX,
  без GPU. Голоса `ru_RU-denis-medium` (мужской) и `ru_RU-irina-medium`
  (женский), ~63 МБ каждый.
- **STT**: [faster-whisper](https://github.com/SYSTRAN/faster-whisper)
  (Whisper на CTranslate2) — модель `small` по умолчанию (~500 МБ,
  `STT_MODEL_SIZE` меняет на `base`/`medium`).

Скачать: `poetry install && poetry run sh download_models.sh` (нужен
интернет один раз; каталог `models/` затем переносится на закрытый сервер
целиком, как `llm/models/`).

## API

- `POST /tts` `{"text", "voice"?}` → `audio/wav` (речь заявителя).
- `POST /stt` multipart-файл `audio` → `{"text"}` (реплика оператора).
- `GET /health` → доступные голоса, модель распознавания.

Доступ — по заголовку `X-Service-Token` (тот же принцип, что у
`arm_api` ↔ `arm_voip`). Вызывающая сторона — `arm_voip`
(`src/arm_voip/tts.py`, `src/arm_voip/stt.py`).

## Замеры (CPU, без GPU)

После прогрева (`VOICE_WARM_UP=1`, включено по умолчанию) синтез фразы из
одного предложения — около 0.1–0.2 с. Первый вызов после старта процесса
может занимать до 15–20 с (инициализация ONNX Runtime) — поэтому прогрев
и делается на старте, а не на первом звонке.
